# amina-workshops

Тестовый прототип многостраничного сайта мастер-классов Амины Губиевой.

## Что внутри
- Главная страница-каталог.
- Две отдельные страницы мастер-классов.
- Структура для Pages CMS.
- Сборка на Eleventy.
- Подготовлено для бесплатного хостинга Cloudflare Pages.

## Cloudflare build
Build command: `npm run build`
Build output directory: `_site`
